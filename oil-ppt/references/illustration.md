# 概念插画

用 `oil-visual` 制作配图，让抽象动作、取舍和关系变成能看见的物件或场景。PPT 默认使用模式 B 的透明素材，标题、标签、命令和准确关系由原生 HTML/CSS/SVG 承担。用户明确需要整张独立解释图时才选择模式 A，并按其文字校验流程执行。

## 先选择画面

- 只在插画比真实界面、截图或结构图更容易讲清本页时使用；不按页数配额加插画。素材职责和官方图标的选择见 `media.md`。
- 每张配图只表达一个主要动作或关系。先描述物件怎样被选择、保存、分开、重叠、交换或组合，再决定是否需要人物。
- 用形状、位置、朝向和状态差异表达含义。忽略标题后，观众仍应看得出主要动作；不能只画一个与主题有关的物件，依靠大段文字解释全部关系。
- 人物、动物、物件和装饰都可独立使用。只有人物的操作、视线或协作能够帮助理解时才加入角色，不自动安排人物与动物，也不重复使用无关的“站在设备旁”场景。

## 制作顺序

### 1. 写简短画面说明

在制作记录中明确以下信息，不把内部设计说明写进观众大纲：

```text
本页判断：观众需要理解什么？
可见对象与动作：谁或什么对象，发生怎样的变化或关系？
素材职责：主体插画、独立物件、辅助人物还是装饰？
版位：横竖比例、最终显示区域、相邻文字和需要留白的位置。
构图：主次、朝向、各主体位置，以及哪些标签由页面提供。
```

### 2. 先布局，再生成

- 先在单页 HTML 确定配图显示区域与文字区域，再选择相应的横版、竖版或多物件构图。角色视线和动作朝向正文或页面中心。
- 主体在最终显示区域中通常占约 65%–80%，原始图片边缘保留安全透明留白。两者分别检查：不能让主体触边，也不能把图片空边误当作页面里的有效画面。
- 需要与多个标签逐一对齐时，先确定主体与标签的位置；需要独立移动的物件分别生成。多个对象同图时明确数量、次序和间隔，不依赖生成图片的像素位置表达准确流程。
- 一个明确的主视觉优先于多张小配图。整套围绕统一墨线、半调网点和配色改变构图，不让所有页都变成相同的左图右字或卡片阵列。

### 3. 用 oil-visual 生成素材

读取 `oil-visual`，使用对应模式的提示词和生成流程，不在本 Skill 维护另一套背景处理指令。提示词依次写清对象、动作与关系、几何位置与朝向、比例与留白，再加入共享画风和排除项。

- PPT 延续黑白灰墨线与克制的暖黄色。其他语义色仅在已有主题和内容需要时使用，整套含义一致。
- 物件用清楚轮廓、材质细节与半调网点体现风格；不为了统一风格给物件加脸、人物或动物。角色被选中时沿用 `oil-visual` 的角色规范。
- 模式 B 不生成解释文字、字母、数字、代码、图表或假 UI；精确标签由页面提供。官方标志直接使用真实素材，插画只负责相关动作或周围场景。
- 生成能力支持原生透明时保留干净 alpha；不支持时走 `oil-visual` 的纯色键控与抠图路径。原图预览的底色不代表实际背景，结合 RGBA 与 alpha 判断。

### 4. 放回真实页面

- 配图优先直接融入背景，不默认套浅灰圆角卡片。色块或容器只有表达边界、状态或层级时才加入；素材自带外框时不再套第二层边界。
- 不可裁切的物件、角色和信息画面用 `contain`。允许裁切的氛围图可用 `cover`；用 `object-position` 保护偏离中心的主体。
- 原图有过多透明空边时，可用页面定位或 SVG viewBox 调整显示范围，保持主体完整、原文件与 alpha 不变。主体过小先修版位与空边，主体被截断或动作错误才针对性重生成。
- 插画与标签、连线按实际主体对齐，不能只按图片外框居中。检查生成图中的多个对象与页面各标签是否一一对应。

### 5. 最后添加装饰

主画面和文字稳定后，用少量网点、短线、纸张边界或暖黄色小色块增强层级与节奏；装饰也可用原生 CSS/SVG，不必全部生成图片。装饰不承担新概念，不遮盖正文、不挤压主体，也不强制每页加入相同图标或角色。空白本身不构成缺陷。

## 验收与修改

1. 看原始素材：选中的对象完整，动作正确，无多余文字或道具；透明图检查 alpha、细线、内部白色与半调网点。
2. 看单页原尺寸与放映缩放：主体容易识别，关系容易看懂，比例、边缘、裁切及标签对齐正确。
3. 看整套缩略图：配色和墨线一致，各页构图有区分，图标、插画和装饰不争夺注意力。
4. 出现问题只修对应层：版式问题调布局，透明空边调显示范围，生成内容错误才重生成。重生成时保留正确对象、画风和关系，只提出针对性的修正。

正式素材保存到项目 `assets/`；新候选使用版本文件名，保留已批准版本。按 `oil-visual` 记录提示词、模式、最终路径和透明处理方式，技术检查不能代替页面里的视觉验收。
