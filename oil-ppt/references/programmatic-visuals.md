# 程序化视觉

UI 场景、流程、关系、对比和数据优先使用页面内 HTML/CSS/SVG 绘制。它们是当前页面源码的一部分，不需要先转换成页面结构数据；只有复杂或高开销视觉才固化为本地 SVG/PNG。

## 选择方式

- 拟真 UI、工作流状态和产品操作：使用原生 HTML/CSS；真实内容必须准确时使用真实截图。
- 抽象关系、连接和结构：使用内联 SVG 或 HTML/CSS，路径和标签都留在当前页面内。
- 小图标：使用内置同一图标家族，只在能缩短识别时间时出现。
- 真实数据图表：从真实 JSON/CSV 生成静态 SVG 或页面内 HTML 图形；保留数据与来源。
- Mermaid 只用于推导结构，正式页面重新排版并统一 token。

最终页面不加载外部 CDN、字体或绘图库，不添加页面脚本。可以在作者阶段使用绘图库，但交付前必须转换成静态 DOM、SVG 或本地素材。

## 场景语法

一个视觉场景通常只有三层：外部语境、核心动作和结果反馈。保留一个主要视觉焦点；其他对象承担上下文，不平均分配重量。用明显的前后状态、方向、比例或局部放大建立兴趣，不用装饰填空。

以 1920×1080 幻灯片为目标，主体占最终视觉区域的 55%–75%。连接优先使用水平或垂直主路径；箭头终点与目标保持呼吸距离。必须标注时使用页面原生文字，正文和关键标签满足投影阅读下限。

所有颜色、字体和圆角优先使用 runtime token。局部 CSS 必须限制在当前 `.s-<id>` 命名空间。HTML 与 SVG 文字必须和它实际覆盖的纯色背景保持至少 2.5:1 对比度。复杂视觉完成后缩小到实际页面尺寸检查：去掉文字是否仍能看懂大致关系、是否只有一个焦点、是否与整套语言一致、是否真正解释内容。
