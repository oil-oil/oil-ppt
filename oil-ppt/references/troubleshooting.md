# 故障处理

以下路径都相对于 `SKILL.md` 所在目录；执行前解析为绝对路径，不调用裸命令，不依赖当前工作目录。

- 环境、依赖或浏览器异常：运行 `scripts/oil-ppt doctor`。
- 不确定从哪种页面起步：运行 `scripts/oil-ppt starter list --json`，再只查看一个相关 starter。
- 页面结构失败：按照 `edit_slide` 返回的真实文件、行号、selector 和问题修复该页。
- 素材失败：依据检查结果修正当前页面的相对路径、文件格式或 `alt`；浏览器报告破图时重新导出可真实解码的文件，再在正式预览中人工核对实际比例和裁切，不扫描其他目录寻找替代文件。
- 浏览器检查失败：只修改问题所在页面，然后重新运行 `scripts/oil-ppt status <项目> --json`。
- 预览陈旧：执行状态机返回的预览命令；不要直接修改 `预览.html`。
- 最终构建陈旧：先确认当前正式预览，再执行状态机返回的构建命令。

如果精确入口不存在或不可执行，报告完整路径并停止；不搜索替代入口，不直接调用内部 Python 模块绕过入口。

不直接编辑生成的 `预览.html`、`演示文稿.html` 或公共 runtime。程序在预览和构建前后必须保持所有 `slides/*.html` 字节不变。
