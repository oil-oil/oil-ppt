# oil-slides 风格手册

一套只属于 oil 的技术幻灯片风格。基调:**克制、清爽、可读;干净,不冷;真诚,不端着。**

视觉与 oil-html 是同一套设计语言:白底黑字、细网格纹理、黑白灰为底、暖黄做唯一常驻色、漫画墨水插画配蒙版色块容器。所需的色值、字号、版式已全部内联在本手册,不依赖别的文件。本手册覆盖:固定舞台、版式模板、文字风格、插画配图。

---

## 〇、可视化优先,克制为纲(第一原则,高于一切)

幻灯片是用来「**看懂**」的,不是用来「读完」的。排版好的文字 = 干瘪。一页堆 4–6 条 bullet,观众既记不住也不想看,分享出去也没人转。

**两条必须同时成立,缺一不可:**

1. **可视化优先** —— 每页都要有一个「主视觉」承载信息(结构图 / 墨水插画 / 关系图 / 极简数据图)。文字是注解,不是主体。**先问「这页用什么图能让人一眼看懂」,再写字。**
2. **克制为纲(少才能看清)** —— 一页一个 idea、一个主视觉、信息单元 ≤3、大量留白。可视化是为了**减负**,不是加料。一个图要配一大段字才看懂 = 图没选对。

> 自检:把这页的字几乎删光,只看图,还能看懂大概吗?能 → 对了。不能 → 这还是「文字配图」,不是「可视化」,重做。

### 内容 → 怎么画(把「说」换成「画」)

| 内容类型 | 干瘪做法(禁止) | 可视化做法 |
|---|---|---|
| 一个概念 / 判断 | 大标题 + 一段说明 | 配一张**墨水插画**(视觉隐喻,放蒙版色块容器),标题一句话,正文极少 |
| 结构 / 分层 | 列 5 条 | 画成栈 / 层 / 关系图,**高亮**重点那层 |
| 对比 | 两栏文字 | 两栏 + 图形/图标差异化,用颜色区分立场 |
| 流程 / 步骤 | 「第一步…第二步…」 | `输入 → 执行 → 输出` 横向箭头流 |
| 数据 / 程度 | 写句「很多 / 更稳」 | 一个 Inter 800 超大数字 + 一根小条 / 一组点 |
| 罗列能力 | 4–6 条 bullet | 2×2 卡片,每张配一个**小线描图标** + 一行字 |
| 真实产品 / 界面 / 文档 | 干说「它长这样」 | **带壳截图**(浏览器窗口壳 + 部分溢出),见 `screenshot-frame.md` |

### 每页都要有「主视觉」

- **概念 / 章节 / 封面 / 收束页**:配**墨水插画**,默认放进蒙版色块容器(见 `references/illustration.md`)。这几类页最容易干瘪,**默认就要配图**,不要做成纯文字陈述页。
- **结构 / 对比 / 流程 / 数据页**:用 CSS 图示(栈 / 双栏 / 箭头流 / 数字条),一处暖黄高亮落在重点上。
- **小图标**:网格卡片别做成纯文字框,每张配一个朴素小图标(inline SVG,单色黑描边,跟插画同语言)。
- **真实界面 / 产品页 / 文档**:用**带壳截图**(ego-browser 抓真图 → HTML 浏览器壳,部分溢出「露一部分」),见 `references/screenshot-frame.md`。真实证据比自画 UI 有说服力。

### 克制的硬约束

- 每页信息单元 ≤3(主视觉算一个)。超了 → 拆页,宁可多两页。
- 每页只有一处暖黄高亮楔入。
- 文字到「看图就懂」就停,别再补充说明。
- 留白是内容的一部分,不要填满。

## 一、固定舞台(技术地基,不可改)

- 每页 1920×1080 创作,手机也保持 16:9,**不重排**。
- 浏览器预览默认**宽度铺满**:`scale = window.innerWidth / 1920`,舞台从 `left:0; top:0` 开始。不要用 `Math.min(innerWidth / 1920, innerHeight / 1080)` 做默认预览,它会在宽屏或浏览器侧栏场景产生左右黑边。
- 舞台外背景用白色或同款网格底,不要用黑色 letterbox。黑边只会让作品看起来像没铺满,除非用户明确要求影院式留黑。
- 宽度铺满后如果高度超出视口,允许 `.deck-viewport` 纵向滚动;不要为了塞进视口把左右留黑。
- 必须包含 `viewport-base.css` 全文。
- 切页用 `.active` 控 `visibility/opacity`,**绝不**用 `display:none/block`(后面的 `display:flex` 会让所有页同时显示)。
- 加 `prefers-reduced-motion` 支持(viewport-base.css 已含)。
- **入场动画和 transform 居中不能同用**:带 `.reveal` 入场类的元素,动画的 `transform` 会覆盖元素自身的 `translateX(-50%)` 居中,导致整块偏出画面。要居中的元素一律用 `left:0; right:0; margin:0 auto`(块)或 `text-align:center`(文本)居中。

### 布局硬底线:成组模块优先 flex/grid

- 流程卡、步骤卡、能力卡、图标条、对比列、手机内的小组件,默认用 flex/grid 管布局,用 `gap`、`minmax()`、`min-width:0`、固定 `aspect-ratio` 和 `overflow:hidden` 控制边界。
- 不要把 3 个小卡片用绝对定位一个个摆到画面上。绝对定位只适合大块版式骨架,不适合卡片内部内容。
- 卡片文字先用自然流布局,给标题和正文留足高度。正文最多两行;超过两行就改短,不要缩到 18px 以下硬塞。
- 图标条必须有明确宽度和网格列数,例如 `display:grid; grid-template-columns:repeat(16,minmax(0,1fr)); gap:7px; overflow:hidden;`。不要让横向图标条自然撑开。
- 每页出图前,把封面流程卡、底部图标条、对比卡、手机预览这些高风险区域放大检查一次。

## 二、色与字(与 oil-html 同源)

```
--slide-bg   #ffffff   纯白(底,永远不变)
--ink        #1a1a1a   近黑(标题/正文)
--ink-2      #555555   次级文字
--ink-3      #999999   辅助小字
--border     #e8e8e8   边线
--surface    #f7f7f8   浅灰面(卡片底)
--hl         #ffe28a   荧光笔高亮暖黄(楔入,一页一处)
--illo-bg    #f9f0d8   插画色块容器暖黄底
```

背景纹理(每页都有,和 oil-html 同手法,是「白底不空」的关键):

```css
/* 细网格铺满舞台,可再叠一层 radial-gradient 蒙版让四周淡出 */
.slide::before {
  content: ''; position: absolute; inset: 0; pointer-events: none;
  background-image:
    linear-gradient(rgba(0,0,0,.03) 1px, transparent 1px),
    linear-gradient(90deg, rgba(0,0,0,.03) 1px, transparent 1px);
  background-size: 48px 48px;
}
```

字体:

- 全部用 `Inter`(拉丁/数字/标题字重) + `Noto Sans SC` / 系统 `PingFang SC`(中文),从 Google Fonts 加载 Inter + Noto Sans SC,和 oil-html 同一个字体栈。
- 大数字用 Inter 800,收字距 `letter-spacing: -0.03em`。
- **高亮楔入(荧光笔,本风格的强调手法)**:一句话里只有 1 个词垫暖黄高亮条——`background: linear-gradient(transparent 58%, var(--hl) 58%, var(--hl) 94%, transparent 94%)`,像马克笔划过重点。字色不变(仍近黑),不斜体、不换字体、不放大。一页最多一处。

排版手感(黑白强对比 + 大留白):

```
封面 hero      132px / line-height 1.18 / 字重 800 / 中文不收紧字距
章节标题 h2    96px  / 1.2  / 700
要点标题       52px  / 1.3  / 600
正文/副标题    30–34px / 1.6–1.7 / 400
代码           ~28px 等宽
最小字号       22px(1920 舞台上再小就看不清)
```

中文标题 `letter-spacing: 0`(不要负字距);只有英文大写小标签用正字距 `.12em–.16em`。

## 三、密度:默认演讲型(大字少字 + 主视觉)

- 一页一个 idea,大标题,留白足。但「少字」不等于「干瘪」——省下的空间留给**主视觉**(见〇),不是留空。
- 信息单元 ≤3,内容多就**拆页**,不要缩字也不要堆 bullet。
- 单页内容不溢出、不重叠、不出现局促小字。浏览器预览为了宽度铺满可以让页面纵向滚动,但单张 1920×1080 舞台内部不能滚动。

## 四、五个版式模板

样张实现见 `assets/examples/sample-deck.html`。每个模板都是三层:白底网格 → 插画/色块中景 → 文字前景。

1. **封面**:左侧内容列(英文小标签带前置横线 → hero 标题含一处高亮楔入 → 副标题),右侧一个大蒙版色块容器,插画从容器探出或被容器边裁切;底部一行小 meta。**不放署名页**。
2. **章节页**:超大**网点填充序号**(半调漫画感,是签名元素)+ 章节标题 + 一句说明。序号 CSS:

   ```css
   .chapter-num {
     font: 800 380px/1 'Inter'; letter-spacing: -0.04em;
     background-image: radial-gradient(circle, #1a1a1a 2px, transparent 2.2px);
     background-size: 13px 13px;
     -webkit-background-clip: text; background-clip: text; color: transparent;
   }
   ```

   想低调时改用 `color: #e8e8e8` 的实色大数字。
3. **要点页(演讲型)**:小标签领起,下面 ≤3 行,每行 = 序号(Inter 800)+ 粗标题 + 一句 muted 说明,行间细分隔线(`--border`)。
4. **代码演示页**:深色代码卡(`#1a1a1a`,圆角 + 轻投影 `0 8px 24px rgba(0,0,0,.08)`)悬浮在白底网格上;语法配色克制:默认字 `#d4d4d4`、关键字白色 700、字符串暖黄 `#ffd666`、注释 `#777`。右侧可放一栏「要点注解」。
5. **收束页**:居中一句话,含一处高亮楔入;下面一行小 kicker。不堆联系方式。

## 五、下一页提示(演讲辅助)

每页右下角自动显示**下一页的标题**,供演讲时参考。

- 实现:每个 `.slide` 加 `data-next="下一页标题"`,JS 注入右下角小卡(近黑上边线 + 「下一页 →」+ 标题)。
- 按 `N` 整场隐藏/显示(给观众放映或导出时关掉)。
- 样式克制:不抢正文,右对齐小字。

## 六、墨水插画(主视觉之一,不是可有可无)

漫画墨水 + 半调网点插画是本风格的招牌主视觉,和 oil-html 完全同一套角色与画风:**火柴人主角(圆头、圆框眼镜)+ 黄色胖边牧同伴**,九成黑白灰、暖黄只在边牧和少量点缀。生成与摆放规范见 `references/illustration.md`。

- **默认就配,不等点名**:封面 / 章节 / 概念判断 / 收束页,默认各配一张(这几类最容易干瘪)。结构/对比/流程页用 CSS 图示,不用插画。
- **默认放进蒙版色块容器**:圆角矩形暖黄色块(`--illo-bg`),插画一部分露出、一部分被容器边裁掉,或头顶探出色块顶边。裸放白底是例外,不是默认。
- 对角落位、容器可溢出 slide 边缘,**不压正文**,一页最多一张。
- 成本提示:每张插画一次生图调用。用户说「先不配图」时才跳过,做纯结构版。
- **真实界面别画、要截**:产品页 / 软件界面 / 官方文档,用带壳截图(`references/screenshot-frame.md`),不用插画、也别画 CSS 假 UI。

## 七、文字风格(最重要)

幻灯片上的每一个字都遵守这套。它比视觉更能暴露"是不是 AI 写的"。底层跟 `~/.claude/skills/oil-tone/SKILL.md` 一致(真诚平实、严禁编造、没 AI 味),本节是幻灯片场景的加严特化;某句文案拿不准时回 oil-tone 翻。

**要:**
- **真诚温暖**,像跟朋友讲清楚一件事。
- **简单易懂**,复杂的事用大白话拆开。
- **每句有信息量**,能删就删。
- 口语化的连接和语气是允许的(其实、就是说、自己的话)。

**不要(硬性):**
- **严禁编造**:数字、案例、个人经历、「我试过」的说法,材料里没有的一律不写。宁可少一页,不编一句。
- **平铺直叙,不用钩子/口号**(最常踩):不写「接个模型,还不够」「不只是 X」「真正的 Y」「X,够了吗?」这类反差悬念、设问卖关子或口号式压缩。**直接、完整地把要点说出来**,像面对面讲话那样。标题宁可朴实一点,也不要"金句感"。
- **不提升立意 / 不上价值**:不写「重新定义」「改变了我对 X 的认知」「这不仅仅是工具,更是一种思维方式」这类拔高。就事论事。
- **不说套话空话**:不写「在当今时代」「随着 AI 的发展」「众所周知」这类开场垫话。
- **不堆砌名词**:不靠一连串术语显得高级;一句话里别塞三个以上专有名词。
- **不浮夸**:禁用「颠覆」「革命性」「炸裂」「绝绝子」「遥遥领先」「极致」「震撼」;**少用感叹号**。

**标题写法**:平铺直叙——把要点直接、完整地说成一句人话(你面对面会怎么说,就怎么写)。也可以是一个自然的问句。高亮楔入(那个**垫暖黄的词**)只是给一个**朴素的关键词**划重点,不是用来造金句——别为了有个强调词而把句子写成口号。

**改写示例:**
| ✗ 钩子 / 套话 / 拔高 | ✓ 平铺直叙 |
|---|---|
| 「接个模型,还不够」(反差钩子) | 「企业 Agent 不是接个模型就能用」 |
| 「云电脑,不只是远程桌面」 | 「云电脑现在还能当 Agent 的工位」 |
| 「重新定义技术分享的边界」 | 「把复杂流程删掉,做自己的幻灯片」 |
| 「五大维度全面解析架构精髓」 | 「这套东西分三块,我一个个说」 |

> 一句话自检:如果这句话**换成一个真人、面对面、会不会这么说**?不会(太像广告词/太像金句),就重写成大白话。

### 商单 / 恰饭内容(单独一套硬规则)

做品牌合作 deck 时,最大的坑不是用了夸张的词,而是**擦掉了广告的口号词、却原样搬了广告的论证骨架**——工整复述甲方的产品框架、给出"天然满足/唯一最优"的无条件结论、用"扛得住/拎包入住"替客户站台。词干净了,骨子还是软文,一样露馅。

可信度来自两个动作:**「克制」和「我自己」**。校准方法:把"讲边界"那种诚实姿态,**反向注入到每一个卖点页**。

- **开场就声明合作**:第一页口播/角标点明"这期是和 X 的合作,但怎么讲我自己说了算"。主动暴露利益关系,后面"我自己用下来"才有分量。
- **每个卖点挂个人视角**:不复述甲方框架,而是"我最在意哪条 / 我试过哪个 / 哪些我没验 / 我没法核实"。明说亲测 vs 听说——反而让"我试过"的部分更可信。
- **保留并讲足边界**:大方给出"这东西不适合的场景"。软文不敢说"这活别用我",这正是你区别于软文的地方,是全篇的可信度压舱页。
- **用一个你真踩过的小坑替代大数字**:具体的、可被读者对照自己需求检验的细节,比任何"40% 企业"都有说服力。第三方数据能不用就不用;要用必须标来源、只一行不展开。
- **甲方的口号词降级成你的判断**:"天然满足/唯一路径/全面领先"→"对我在意的点对得比较齐,不能说完美";品牌必保词一句带过,不反复喊。
- **硬交付一个不丢**:产品点名、关键能力、必保品牌词、指定案例方向该出现都出现——只是用你的口吻包装,不照搬甲方话术。
