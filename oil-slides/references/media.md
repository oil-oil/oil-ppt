# 素材

只读取用户明确提供、附加或指向的输入材料；不扫描它们的同目录或桌面。

在 `preview` 前把要展示的最终素材放入项目 `assets/`，outline 只写项目相对路径，例如 `image: "assets/demo.png"`。

## 视觉计划

- 真实产品、网页、文档或案例是论据时，用真实截图或真实材料承担锚点。
- 抽象机制、设计哲学或工作流没有外部证据时，优先用程序化 SVG、HTML/CSS 关系图或无事实指向的概念插画。
- 每张图片必须回答一个明确问题；只提供氛围、与正文没有关系的图片不算锚点。
- AI 生成插画不得包含文字、数字、标签、假 UI 或图表；需要文字时由页面原生 HTML 承担。
- 真实产品截图可以保留其原生文字。程序化关系图需要标签时，优先把文字做成页面原生内容，不烘焙进位图。
- 用户说“参考这个文件”但文件未附加、路径不可用或无法读取时，先补齐输入；不能把未参考的自选方向描述成参考结果。

## 获取渠道

- 真实网页、产品或文档：使用浏览器打开用户指定的对象并截图。
- 真实照片：用图片搜索定位，回到 Pexels、Unsplash 等原始授权页确认后使用；不直接使用普通搜索结果图。
- 概念插画或视觉隐喻：使用当前环境的图像生成能力。
- 流程、关系、对比和数据：使用 HTML/CSS/SVG 程序化组件。

生成概念插画前读取 `illustration.md`。
生成 UI 场景、关系图或图表前读取 `programmatic-visuals.md`。

## 边界

- 产品界面、数据、案例、真人和其他证据必须使用真实素材。
- AI 生成只用于无事实指向的概念插画、视觉隐喻和氛围图。
- 用户请求制作演示时，可为预览直接准备上述非敏感素材；用户确认预览即确认其中的视觉方案，不再二次询问。
